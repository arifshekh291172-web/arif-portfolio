# Arif Software Studio

A professional full-stack service platform concept showcasing software development services and projects.

## Capabilities
- **AI & RAG Systems**: Retrieval-Augmented Generation, document vector search.
- **Computer Vision**: Spatial AI, hand tracking, and automation.
- **IoT Firmware**: Embedded C++ for ESP32/ESP8266 and sensor telemetry.
- **Full-Stack Engineering**: React, Node.js, Express, MongoDB.

## Run
```bash
npm install
npm start
```
Starts at [http://localhost:5050](http://localhost:5050).
