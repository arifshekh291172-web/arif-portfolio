# Right Source HR

A recruitment platform concept with job listings, applications and administrative job approval workflows.

## Technology Stack
- **Backend**: Node.js & Express RESTful API
- **Frontend**: Responsive HTML5, CSS3, JavaScript
- **Database**: Document Collections / MongoDB format

## Features
- Dynamic vacancy directory with search
- Candidate application intake with portfolio links
- Administrative job approval workflow

## Run
```bash
npm install
npm start
```
Runs at [http://localhost:4000](http://localhost:4000).
